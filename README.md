# Веб-приложение "График отпусков"

> Основано на проекте [Segodnya/vacation-calendar](https://github.com/Segodnya/vacation-calendar)

Простое веб-приложение для совместного планирования отпусков в команде. Позволяет визуализировать периоды отпусков разных сотрудников, видеть пересечения и учитывать выходные/праздничные дни.

Все данные синхронизируются через Firebase и сохраняются между сессиями.

## Особенности

- 📅 **Автоматический календарь** на текущий год с учётом выходных и праздников (через API isDayoff.ru)
- 👥 **Несколько пользователей** с выбором цвета и имён
- ⚠️ **Визуализация пересечений** отпусков (внутри одного пользователя — запрещено, между разными — с предупреждением)
- 💾 **Синхронизация данных** через Firebase Firestore (работает в реальном времени)
- 🔐 **Простая аутентификация** с хешированием пароля через Firebase
- 📱  **Адаптивный интерфейс** с панелью управления и свёртыванием карточек
- 🗑️ **Сброс данных** с очисткой как локально, так и в Firebase

## Технологии

- HTML5, CSS3 (BEM-методология)
- Vanilla JavaScript (ES6+)
- Firebase Firestore (база данных)
- GitHub Pages (хостинг)

## Функциональность

- Автоматическое построение календаря на выбранный год
- Добавление/удаление пользователей и отпусков
- Выбор цвета для каждого пользователя
- Валидация дат отпуска (начало ≤ конец)
- Расчёт продолжительности отпуска в календарных и рабочих днях
- Всплывающее окно с информацией по дням
- Сохранение состояния между сеансами (Firestore)
- Предупреждение о пересечениях отпусков разных пользователей
## Установка и запуск локально

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/SEGODNYA/vacation-calendar.git
   cd vacation-calendar
   ```

2. Открой index.html через Live Server (расширение для VS Code) или любой HTTP-сервер.

## Настройка Firebase

1. Создай проект на [Firebase Console](https://console.firebase.google.com/)
2. Включи **Firestore Database** в тестовом режиме
3. Добавь веб‑приложение в проект и скопируй конфигурацию
4. Вставь конфиг в файл `firebase-config.js`
5. В Firebase Console добавь домен GitHub Pages (`segodnya.github.io`) в **Authorized domains** (Authentication → Sign‑in method)

## Аутентификация

Пароль хранится в Firebase Firestore в виде SHA‑256 хеша. Для входа необходимо знать установленный пароль. По умолчанию пароль можно задать через Firebase Console, создав документ `auth/password` с полем `hash`.

## Развёртывание на GitHub Pages

1. Запушь код в репозиторий
2. В настройках репозитория перейди в **Pages**
3. Выбери ветку `main` и папку `/ (root)`
4. Сайт будет доступен по адресу: `https://ТВОЙ_USERNAME.github.io/vacation-calendar/`
